# wordle-gf

A five-letter word puzzle that reveals a custom message at the end. The game runs directly in a browser and supports the physical keyboard, on-screen keys, and light and dark themes.

1. Open [the game editor](romantic_word_puzzle_for_your_partner.html) in a browser.
2. Set a five-letter answer, or leave the answer blank to reveal the message after six guesses. Edit the six reveal lines and the caption in the settings panel.
3. Use the preview to check the reveal, then download the standalone player HTML and share it.
